# Soup take-home — streamed DPO on a Colab T4

DPO fine-tuning of **Qwen2.5-1.5B-Instruct** with Soup's layer streaming on a free Colab T4,
on a synthetic Russian customer-support preference dataset, and the evidence for a
**SHIP / DON'T SHIP** call.

> Status: data, config, memory prediction, notebook and verification script are ready and
> tested on CPU. The T4 run, measured results and the report are in progress.

## Deliverables

| Task item | Where |
|---|---|
| Report (≤ 2 pages) | `REPORT.md` *(in progress)* |
| Raw timestamped logs | `logs/` (`run.log`, `train_steps_*.jsonl`, `env_*.json`, …) |
| Raw `nvidia-smi` output | `logs/nvidia-smi_*.txt`, `logs/nvidia-smi_train_*.csv` |

## Layout

```
generate_soup_dpo_professional.py   synthetic RU support-ticket DPO dataset (500 pairs, 20 categories)
style_reference.py                  compares ticket style with real complaints (Yandex Geo Reviews 2023)
SOURCES.md                          data sources, method, known limitations
soup_dpo_data/                      generated dataset + dataset_report.json
prepare_soup_data.py                -> data/: soup `format: dpo` (chat messages) + per-row metadata
soup.yaml                           training config (every value explicit, see comments)
memory_budget.py                    Part 1: VRAM prediction before training
soup_dpo_t4.ipynb                   Colab notebook: env, data checks, parity, budget, DPO run, verification
verify_training.py                  Part 2: LOADED / MOVED / ACTIVE / LEARNED / CONTROL checks
logs/                               raw outputs
```

## Reproduce

```bash
python generate_soup_dpo_professional.py      # -> soup_dpo_data/
python prepare_soup_data.py                   # -> data/
python memory_budget.py                       # Part 1 prediction
python verify_training.py --self-test         # CPU: shows the Part 2 check discriminates
```

Then upload the folder to `MyDrive/soup_project`, open `soup_dpo_t4.ipynb` in Colab on a
**T4** runtime and run the sections in order.

Environment: `soup-cli[train]==0.75.1`, Python ≤ 3.12 (Colab 3.13 uses `--ignore-requires-python`,
as in Soup's own notebook), Colab preinstalled `torchao` removed.
